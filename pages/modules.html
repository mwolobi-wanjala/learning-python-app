16. Modules & Packages

Organize your code into reusable files and tap into Python's massive ecosystem.

Home / Lesson 16

Organize Code With Modules

A module is a Python file containing reusable code. A package is a folder that groups related modules. Importing lets one file use code from another instead of copying it. This keeps large projects easier to test and maintain.

# helpers.py
def calculate_tax(amount):
    return amount * 0.16

# checkout.py
from helpers import calculate_tax
print(calculate_tax(100))

The checkout program reuses the tax function from another file. Teams use modules for authentication, database access, payments, and reporting so each part has a clear responsibility.

pip installs third-party packages from PyPI, the Python Package Index. A virtual environment creates an isolated project space so one project's dependencies do not interfere with another. The if __name__ == "__main__" check marks code that should run only when a file is started directly.

Key words: module (one Python file), package (group of modules), dependency (code your project needs), PyPI (package repository), virtual environment (isolated install), import, and entry point (where execution begins).

Importing Modules

import math
print(math.sqrt(16))
print(math.pi)

from random import randint
print(randint(1, 100))

import datetime
now = datetime.datetime.now()
print(now.year)
4.0 3.141592653589793 42 2025

Creating Your Own Module

Create a file mymath.py:

# mymath.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159

Now use it in another file:

import mymath

print(mymath.add(5, 3))
print(mymath.multiply(4, 6))
print(mymath.PI)
8 24 3.14159

__name__ == "__main__"

Ensure code only runs when the file is executed directly.

# mymodule.py
def greet(name):
    return f"Hello, {name}"

if __name__ == "__main__":
    print(greet("JANS TECH"))

This block runs only when mymodule.py is executed directly, not when imported.

Installing Packages with pip

# In your terminal:
pip install requests
pip install pandas
pip install flask

# List installed packages
pip list

# Save requirements
pip freeze > requirements.txt

# Install from requirements
pip install -r requirements.txt

Virtual Environments

# Create a virtual environment
python -m venv myenv

# Activate it
# Windows:
myenv\Scripts\activate
# Mac/Linux:
source myenv/bin/activate

# Install packages inside
pip install requests

# Deactivate
deactivate

Common Errors & Bugs

ModuleNotFoundError: No module named 'requests'

Cause: The package isn't installed. Run pip install requests.

ImportError: cannot import name 'sqrt' from 'math'

Cause: Typos or importing from the wrong module. Check the docs.
