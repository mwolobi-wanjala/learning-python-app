16. Modules & Packages

Organize your code into reusable files and tap into Python's massive ecosystem.

Home / Lesson 16

Organize Code With Modules

A module is a Python file containing reusable code. A package is a folder that groups related modules. Importing lets one file use code from another instead of copying it. This keeps large projects easier to test and maintain.

# helpers.py
def calculate_tax(amount):
    return amount * 0.16

# checkout.py
from helpers import calculate_tax
print(calculate_tax(100))

The checkout program reuses the tax function from another file. Teams use modules for authentication, database access, payments, and reporting so each part has a clear responsibility.

pip installs third-party packages from PyPI, the Python Package Index. A virtual environment creates an isolated project space so one project's dependencies do not interfere with another. The if __name__ == "__main__" check marks code that should run only when a file is started directly.

Key words: module (one Python file), package (group of modules), dependency (code your project needs), PyPI (package repository), virtual environment (isolated install), import, and entry point (where execution begins).

Importing Modules

import math
print(math.sqrt(16))
print(math.pi)

from random import randint
print(randint(1, 100))

import datetime
now = datetime.datetime.now()
print(now.year)
4.0 3.141592653589793 42 2025

Dates, Math, and JSON

The standard library includes focused modules for common tasks. datetime represents dates, math provides mathematical functions, and json converts between Python data and the text format used by many APIs.

from datetime import date
import json
import math

today = date.today()
record = {"year": today.year, "area": math.pi * 3 ** 2}
json_text = json.dumps(record, indent=2)

print(json_text)
print(json.loads(json_text)["year"])
{ "year": 2026, "area": 28.274333882308138 } 2026

json.dumps() creates JSON text for a file or HTTP request. json.loads() parses JSON text back into Python objects. Always validate data from outside your program before trusting its fields.

Regular Expressions

The re module searches text using patterns. It is useful for controlled validation and extraction, but a simple string method is usually easier when it is enough.

import re

text = "Contact: learner@example.com"
match = re.search(r"[\w.-]+@[\w.-]+\.\w+", text)

if match:
    print(match.group())
learner@example.com

The raw string prefix r keeps backslashes readable. search() returns a match object or None; group() extracts the matched text. Patterns should be tested with valid and invalid examples before they are used for real input.

Creating Your Own Module

Create a file mymath.py:

# mymath.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159

Now use it in another file:

import mymath

print(mymath.add(5, 3))
print(mymath.multiply(4, 6))
print(mymath.PI)
8 24 3.14159

__name__ == "__main__"

Ensure code only runs when the file is executed directly.

# mymodule.py
def greet(name):
    return f"Hello, {name}"

if __name__ == "__main__":
    print(greet("JANS TECH"))

This block runs only when mymodule.py is executed directly, not when imported.

Installing Packages with pip

pip is Python's package installer. It downloads published packages from the Python Package Index and places them into the active Python environment. Prefer python -m pip because it guarantees that pip belongs to the same Python interpreter used to run your program.

# In your terminal:
    python -m pip install requests
    python -m pip install pandas flask

# List installed packages
pip list

# Save requirements
pip freeze > requirements.txt

# Install from requirements
pip install -r requirements.txt

requirements.txt records dependencies so another computer can recreate the project. Run these commands in the folder that contains your Python files. After installation, test the package with python -c "import requests; print(requests.__version__)".

Virtual Environments

A virtual environment is an isolated folder containing its own installed packages. Isolation prevents one project from changing another project's dependencies. A typical project might look like this:

python-project/
|-- myenv/              # isolated environment; usually not committed
|-- app.py
|-- requirements.txt
|-- mymodule.py
# Create a virtual environment
python -m venv myenv

# Activate it
# Windows:
myenv\Scripts\activate
# Mac/Linux:
source myenv/bin/activate

# Install packages inside
pip install requests

# Deactivate
deactivate

After activation, your terminal usually shows (myenv) before the prompt. Install packages only after activation. To leave the environment, run deactivate; your files remain unchanged, but commands use the system Python again.

Common Errors & Bugs

ModuleNotFoundError: No module named 'requests'

Cause: The package isn't installed. Run pip install requests.

ImportError: cannot import name 'sqrt' from 'math'

Cause: Typos or importing from the wrong module. Check the docs.
