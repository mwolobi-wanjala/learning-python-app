What Libraries Are For

A library is reusable code written by someone else. A framework provides a larger structure and rules for building an application. A package is the installable distribution that may contain one or more modules.

# install once in the project environment
pip install requests

# use the library in Python
import requests
response = requests.get("https://example.com")

The program uses a library to make an HTTP request instead of implementing the network protocol itself. Libraries save time and let developers build dependable features for web pages, data analysis, machine learning, games, desktop interfaces, and automation.

Choose a library by checking its documentation, maintenance, license, and security. A data frame is a table-like structure for analysis, an API is a way for programs to communicate, and web scraping means extracting information from web pages where permission allows it.

Key words: library (reusable tools), framework (application structure), package (installable code), API (program-to-program interface), dependency (required package), data frame (table-like data), GUI (graphical interface), and model (learned or structured prediction logic).

Testing and Logging

Tests check behavior automatically; logging records what a running program is doing. Together they make changes safer than relying only on manual clicking and temporary print() statements.

# calculator.py
def add(first, second):
    return first + second

# test_calculator.py
import unittest
from calculator import add

class CalculatorTests(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2, 3), 5)

if __name__ == "__main__":
    unittest.main()

Run it with python -m unittest. A test names a behavior and fails when the result changes unexpectedly. For a real application, use the logging module with levels such as INFO, WARNING, and ERROR so diagnostic output can be controlled without changing the program.
