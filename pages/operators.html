5. Operators

Perform calculations and comparisons with Python's built-in operators.

Home / Lesson 05

Operators Are Instructions

An operator is a symbol or word that tells Python to calculate, compare, or combine values. The values around it are operands. Arithmetic operators calculate, comparison operators ask a question, and logical operators combine questions.

subtotal = 800
discount = subtotal * 0.10
amount_due = subtotal - discount
print(amount_due)  # 720.0

Here * calculates the discount and - subtracts it from the subtotal. A billing system, receipt printer, or budgeting app uses operators to turn business rules into calculations.

// gives whole-number division, % gives a remainder, and ** raises a number to a power. Comparison results are Boolean values, so they can be used by if statements.

Key words: operand (a value being used), expression (code that produces a value), modulus (remainder with %), comparison (a true/false check), and assignment (storing a result).

Arithmetic Operators

These perform mathematical operations on numbers.

a = 10
b = 3

print(a + b)   # Addition
print(a - b)   # Subtraction
print(a * b)   # Multiplication
print(a / b)   # Division (always returns float)
print(a // b)  # Floor division (removes decimal)
print(a % b)   # Modulus (remainder)
print(a ** b)  # Exponent (10 to the power 3)
13 7 30 3.3333333333333335 3 1 1000

Comparison Operators

Compare two values and return True or False.

x = 5
y = 10

print(x == y)   # Equal to
print(x != y)   # Not equal
print(x < y)    # Less than
print(x > y)    # Greater than
print(x <= y)   # Less than or equal
print(x >= y)   # Greater than or equal
False True True False True False

Logical Operators

Combine multiple conditions with and, or, and not.

age = 20
has_id = True

print(age >= 18 and has_id)   # Both must be True
print(age < 18 or has_id)     # At least one True
print(not has_id)             # Reverses the value
True True False

Assignment Operators

Shortcut for updating a variable's value.

count = 10
count += 5   # Same as count = count + 5
print(count)

count -= 3
print(count)

count *= 2
print(count)

count //= 4
print(count)
15 12 24 6

Common Errors & Bugs

ZeroDivisionError: division by zero

Cause: Dividing a number by zero. Always check the divisor before dividing.

num = 10
div = 0
if div != 0:
    print(num / div)
else:
    print("Cannot divide by zero!")
TypeError: unsupported operand type(s) for +: 'int' and 'str'

Cause: Mixing types. Convert with str() or int() before operating.
