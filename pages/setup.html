2. Setup & Installation

Get Python installed on your machine and set up a professional coding environment.

Home / Lesson 02

Understand Your Tools

Python code is written in a file ending in .py. The interpreter is the program that reads that file and runs its instructions. VS Code is an editor: it helps you write code, but Python itself does the running.

The terminal is a text-based window where you type commands. PATH tells the terminal where programs such as Python are installed. An editor extension adds features such as completion, error warnings, and formatting.

python hello.py

# python = start the interpreter
# hello.py = the file to run

Python opens the file, follows the instructions from top to bottom, and prints the result. This is the same workflow used to run scripts that rename files, create reports, or automate office tasks.

Setup Checkpoint

Create hello.py with print("Python is ready"), run it in the terminal, and confirm the message appears. If it does not, check the interpreter selection and PATH before writing a larger program.

Key words: editor (where code is written), terminal (where commands are entered), interpreter (what executes Python), extension (an editor add-on), and formatter (a tool that makes code readable).
