7. Control Flow

Teach your program to make decisions with if, elif, and else.

Make Decisions With Conditions

Control flow decides which instructions run and in what order. A condition is a question that becomes True or False. An if block runs when its condition is true; elif checks another possibility and else handles everything remaining.

balance = 1200
if balance >= 1000:
    status = "Premium customer"
else:
    status = "Standard customer"
print(status)

Python compares the balance, chooses one branch, and skips the other. A bank can use this for account levels, a school for grades, and a login system to allow or deny access.

Indentation is part of Python syntax: the indented lines belong to the decision. A nested condition is an if inside another if; use it when a second question depends on the first.

Key words: condition (a true/false question), branch (one possible path), Boolean (true/false value), nested (inside another block), and ternary expression (a compact one-line choice).

The if Statement

Runs a block of code only if a condition is True.

age = 18

if age >= 18:
    print("You are an adult.")
You are an adult.

if-elif-else

Chain multiple conditions together.

marks = 78

if marks >= 80:
    grade = "A"
elif marks >= 70:
    grade = "B"
elif marks >= 60:
    grade = "C"
elif marks >= 50:
    grade = "D"
else:
    grade = "F"

print(f"Your grade is {grade}")
Your grade is B

Nested Conditions

username = "admin"
password = "1234"

if username == "admin":
    if password == "1234":
        print("Login successful")
    else:
        print("Wrong password")
else:
    print("Unknown user")
Login successful

One-line if (Ternary)

age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)
Adult

Common Errors & Bugs

SyntaxError: expected ':'

Cause: Forgetting the colon (:) after if, elif, or else.

IndentationError: expected an indented block

Cause: Not indenting the block of code under an if statement. Python requires 4 spaces.

# Common logical bug x = 10 if x = 10: # Error! Should be == print("equal")

Cause: Using = (assignment) instead of == (comparison).
