8. Loops

Automate repetitive tasks with for and while loops.

Home / Lesson 08

Repeat Work With Loops

A loop repeats instructions. One pass through the loop is an iteration. A for loop visits each item in a collection, while a while loop repeats as long as a condition remains true.

orders = [12.50, 8.00, 15.75]
total = 0
for amount in orders:
    total += amount
print(total)  # 36.25

Python takes one order amount at a time, adds it to total, and stops after the list is finished. Shops use this to total orders, websites use it to show products, and reports use it to process many records.

range() creates a sequence of numbers, enumerate() gives an item and its position, and zip() processes matching items from two collections. Use break to stop early and continue to skip one iteration.

Key words: iteration (one repetition), iterable (something a loop can visit), loop variable (the current item), infinite loop (a loop that never reaches its stopping condition), and accumulator (a value updated during repetition).

The for Loop

Iterates over a sequence (list, string, range, etc.).

# Loop over a range of numbers
for i in range(5):
    print(f"Iteration {i}")

# Loop over a string
for letter in "JANS":
    print(letter)
Iteration 0 Iteration 1 Iteration 2 Iteration 3 Iteration 4 J A N S

The while Loop

Repeats as long as a condition is True.

count = 1
while count <= 5:
    print(f"Count: {count}")
    count += 1
Count: 1 Count: 2 Count: 3 Count: 4 Count: 5

break & continue

# break exits the loop
for i in range(10):
    if i == 5:
        break
    print(i)

print("---")

# continue skips the current iteration
for i in range(5):
    if i == 2:
        continue
    print(i)
0 1 2 3 4 --- 0 1 3 4

range() Function

print(list(range(5)))         # 0 to 4
print(list(range(2, 8)))      # 2 to 7
print(list(range(0, 10, 2)))  # 0, 2, 4, 6, 8
[0, 1, 2, 3, 4] [2, 3, 4, 5, 6, 7] [0, 2, 4, 6, 8]

enumerate() & zip()

names = ["Javanson", "Alice", "Bob"]

for index, name in enumerate(names, start=1):
    print(f"{index}. {name}")

ages = [25, 30, 28]
for name, age in zip(names, ages):
    print(f"{name} is {age}")
1. Javanson 2. Alice 3. Bob Javanson is 25 Alice is 30 Bob is 28

Iterators and next()

An iterable can produce items one at a time. Calling iter() creates an iterator, and next() asks it for the next value. A for loop performs this work automatically and stops when the iterator is exhausted.

colors = ["red", "green", "blue"]
    color_iterator = iter(colors)

    print(next(color_iterator))
    print(next(color_iterator))
    print(list(color_iterator))
red green ['blue']

After an iterator is exhausted, another next() raises StopIteration. Iterators are useful for streams and large data because they do not need to load every value at once.
