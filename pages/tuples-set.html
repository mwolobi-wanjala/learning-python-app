11. Tuples & Sets

Immutable sequences and unique collections â€” two essential Python structures.

Home / Lesson 11

Choose The Right Collection

Use a list when you need an ordered, changeable collection. Use a tuple for a small group of values that should not change, such as a map coordinate. Use a set when you care about unique values and fast membership checks, not positions.

location = (-1.2864, 36.8172)  # fixed latitude and longitude
skills = {"Python", "SQL", "Python"}
print(skills)  # Python appears once

The tuple protects the location pair from accidental edits. The set removes duplicate skills automatically. A map can use tuples for coordinates, while a registration system can use sets to find unique tags or permissions.

Set operations include union (everything in either set), intersection (shared items), and difference (items only in one set). Tuple unpacking gives names to positions, such as latitude, longitude = location.

Key words: tuple (fixed ordered collection), immutable (not changeable), set (unique collection), unpacking (assigning collection items to names), union, intersection, and difference.

Tuples

Tuples are ordered but immutable â€” you cannot change them after creation.

coordinates = (10, 20)
colors = ("red", "green", "blue")
single = (42,)   # Note the comma!

print(coordinates[0])
print(len(colors))

# Tuple unpacking
x, y = coordinates
print(f"x={x}, y={y}")
10 3 x=10, y=20

Sets

Sets are unordered and contain unique elements only.

fruits = {"apple", "banana", "cherry", "apple"}
print(fruits)   # Duplicates removed

numbers = {1, 2, 3, 4, 5}
numbers.add(6)
numbers.remove(2)
print(numbers)
{'apple', 'banana', 'cherry'} {1, 3, 4, 5, 6}

Set Operations

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)   # Union
print(a & b)   # Intersection
print(a - b)   # Difference
print(a ^ b)   # Symmetric difference
{1, 2, 3, 4, 5, 6} {3, 4} {1, 2} {1, 2, 5, 6}

Set and Tuple Comprehensions

A comprehension builds a collection from a loop. A set comprehension removes duplicates automatically, while a tuple is commonly created by passing a generator expression to tuple().

words = ["python", "api", "python", "web"]
    lengths = {len(word) for word in words}
    length_pairs = tuple((word, len(word)) for word in words)

    print(lengths)
    print(length_pairs)
{2, 3, 6} ('python', 6), ('api', 3), ('python', 6), ('web', 3)

Set order is not guaranteed, so do not write programs that depend on the display order. Sort a set when you need predictable presentation.

Common Errors & Bugs

TypeError: 'tuple' object does not support item assignment

Cause: Trying to modify a tuple. Use a list if you need to modify.

TypeError: unhashable type: 'list'

Cause: Trying to put a list inside a set. Sets only accept immutable items.

KeyError: 'x'

Cause: Removing an element from a set that doesn't exist. Use discard() for safe removal.
