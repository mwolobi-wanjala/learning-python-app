13. File Handling

Read, write, and manage files on your computer with Python.

Home / Lesson 13

Save Information In Files

Variables disappear when a program stops. A file stores data so it can be used later. The mode "w" writes and replaces existing content, "a" appends to the end, and "r" reads.

with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Call the customer tomorrow")

# with closes the file safely after the block finishes

open() creates a file handle, and the with statement closes it even if an error occurs. Notes apps, exports, logs, and simple databases use files to persist information between program runs.

JSON is a text format for structured data that looks similar to Python dictionaries. Serialization converts program data into JSON; deserialization converts JSON back into program data. Use relative paths carefully so the program opens the intended file.

Key words: file handle (connection to an open file), mode (read/write behavior), append (add to the end), overwrite (replace), encoding (how text is stored), JSON, serialize, and deserialize.

Writing to a File

with open("notes.txt", "w") as file:
    file.write("Hello, JANS TECH!\n")
    file.write("Learning Python is fun.\n")

print("File created!")
File created!

Modes: "w" (write/overwrite), "a" (append), "r" (read), "x" (create new).

Reading a File

with open("notes.txt", "r") as file:
    content = file.read()
    print(content)

# Read line by line
with open("notes.txt", "r") as file:
    for line in file:
        print(line.strip())

Appending to a File

with open("notes.txt", "a") as file:
    file.write("New line added!\n")

with open("notes.txt", "r") as file:
    print(file.read())

Working with JSON

import json

data = {
    "name": "Javanson",
    "age": 25,
    "skills": ["Python", "JavaScript"]
}

# Write JSON
with open("data.json", "w") as file:
    json.dump(data, file, indent=2)

# Read JSON
with open("data.json", "r") as file:
    loaded = json.load(file)
    print(loaded["name"])
    print(loaded["skills"])
Javanson ['Python', 'JavaScript']

Common Errors & Bugs

FileNotFoundError: [Errno 2] No such file or directory: 'missing.txt'

Cause: Trying to read a file that doesn't exist. Check the path or use os.path.exists().

PermissionError: [Errno 13] Permission denied

Cause: The file is open in another program or you lack permission.

UnicodeDecodeError: 'utf-8' codec can't decode byte

Cause: Reading a binary file as text. Use "rb" mode for binary files.
