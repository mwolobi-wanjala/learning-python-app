1. Introduction to Python

Discover what Python is and why it powers everything from websites to AI.

Understand It First

Python is a programming language: a way of writing precise instructions that a computer can follow. It is called high-level because its words are easier for people to read than machine instructions, and general-purpose because it can be used for websites, data, automation, and many other jobs.

Python is interpreted, which means the Python interpreter reads and runs your program. A variable stores a value, while a function is a named group of instructions that can be reused.

name = "Amina"          # store text in a variable
print("Hello, " + name) # ask Python to display a message

Read the code from top to bottom: first Python stores the text, then it joins the greeting with the stored name, and finally print() displays the result. This same pattern is used in welcome screens, receipts, reports, and notifications.

Where Python Is Used

A shop can use Python to total orders, a school can use it to process grades, and a web service can use it to respond to users. The code stays readable, so another developer can understand and improve it later.

Key words: interpreter (the program that runs Python), library (ready-made code), script (a Python file), and output (what the program produces).

Syntax, Comments, and Indentation

Python uses readable statements and indentation instead of curly braces. A colon starts a block, and the indented lines belong to that block. Comments begin with # and are ignored by Python; use them to explain a decision, not to repeat obvious code.

# Store the order total before applying the discount.
total = 120

if total >= 100:
    discount = 10
    total -= discount

print(total)

The blank lines are for people, the comment documents the purpose, and the four-space indentation defines the body of the if statement. Python reads the code from top to bottom, so a name must be created before it is used.

What is Python?

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes code readability and lets you write programs in fewer lines than languages like C++ or Java.

Its design philosophy: "Simple is better than complex."

Common Errors & Bugs

Beginners often run into these:

IndentationError: unexpected indent File "main.py", line 1 print("Hello") ^ IndentationError: unexpected indent

Cause: Mixing tabs and spaces or adding extra spaces. Python is strict about indentation.

SyntaxError: invalid syntax File "main.py", line 1 print "Hello" ^ SyntaxError: Missing parentheses in call to 'print'

Cause: Forgetting parentheses around print arguments (Python 2 style).
