4. Data Types

Understand the fundamental building blocks of every Python program.

Home / Lesson 04

Why Data Types Matter

A data type tells Python what kind of value it is handling. An int is a whole number, a float is a decimal number, a str is text, and a bool is either True or False. None means a value is currently missing or intentionally empty.

age_text = "21"          # text received from a form
age = int(age_text)      # convert text to a number
can_vote = age >= 18      # result is True or False
print(type(age), can_vote)

Input from a keyboard or web form normally arrives as text, even when the user types a number. Type conversion changes it into a number before arithmetic or comparison. A registration system uses this when checking age, quantity, or price.

Use type(value) while learning or debugging. Choosing the correct type prevents errors such as trying to add text to a number.

Key words: type (the kind of data), conversion (changing one type to another), string (text), Boolean (true/false data), and None (no value yet).

Core Data Types

Python has several built-in types. The most common are:

  • int — Whole numbers: 10, -3, 2025
  • float — Decimal numbers: 3.14, -0.5
  • str — Text: "Hello", 'JANS TECH'
  • bool — True or False: True, False
  • NoneType — Represents "no value": None
age = 25                # int
price = 99.99           # float
name = "Javanson"       # str
is_student = True       # bool
result = None           # NoneType

print(type(age))
print(type(price))
print(type(name))
print(type(is_student))
print(type(result))
<class 'int'> <class 'float'> <class 'str'> <class 'bool'> <class 'NoneType'>

Type Conversion

You can convert between types using built-in functions:

num_str = "100"
num_int = int(num_str)      # "100" → 100
num_float = float("3.14")   # "3.14" → 3.14
text = str(2025)            # 2025 → "2025"

print(num_int + 50)         # 150
print(num_float * 2)        # 6.28
print(text + " is the year")
150 6.28 2025 is the year

Common Errors & Bugs

TypeError: can only concatenate str (not "int") to str

Cause: Trying to add a string and an integer: "Age: " + 25. Fix it with "Age: " + str(25) or use an f-string.

ValueError: invalid literal for int() with base 10: 'abc'

Cause: Trying to convert a non-numeric string to int. Always validate input.
