3. Variables

Learn how to store, label, and reuse data in your programs.

Home / Lesson 03

Understand Variables

A variable is a name attached to a value. Think of it as a labeled box: the label is the variable name and the contents are the current value. Python is case-sensitive, so total and Total are different names.

price = 25
quantity = 3
total = price * quantity
print(total)  # 75

Python stores the price and quantity, multiplies them, and stores the answer in total. A shopping cart, invoice, or payroll system uses this pattern to keep changing information in named values.

Assignment uses = to store a value. A variable can be reassigned when the real-world value changes, such as when a customer adds another item.

Key words: value (the data stored), assignment (storing data with =), keyword (a reserved Python word), and multiple assignment (giving several variables values in one statement).

What is a Variable?

A variable is a named container that stores a value in memory. Think of it as a labeled box where you keep data for later use.

name = "Javanson"
age = 25
country = "Kenya"

Here, name, age, and country are variables holding different values.

Naming Rules

  • Must start with a letter or underscore (_)
  • Can contain letters, numbers, and underscores
  • Case-sensitive: Name ≠ name
  • Cannot use Python keywords (if, for, class, etc.)

Good vs Bad Names

# Good
user_name = "Alice"
total_price = 250.75

# Bad
2name = "Bob"     # starts with number
user-name = "Eve" # uses hyphen
class = "Math"    # reserved keyword

Reassigning Variables

Variables can change value at any time:

score = 50
print(score)   # 50
score = 90
print(score)   # 90
50 90

Multiple Assignment

x, y, z = 1, 2, 3
a = b = c = 100
print(x, y, z)
print(a, b, c)
1 2 3 100 100 100

Common Errors & Bugs

NameError: name 'username' is not defined

Cause: You used a variable before defining it, or you misspelled the name.

SyntaxError: invalid syntax user-name = "Eve"

Cause: Hyphens are not allowed in variable names. Use underscores.
