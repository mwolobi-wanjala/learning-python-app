12. Dictionaries

Store data as key-value pairs for ultra-fast lookups.

Home / Lesson 12

Look Up Data With Dictionaries

A dictionary stores key-value pairs. The key is the label used to find information, and the value is the information returned. Unlike a list, you normally look up a dictionary value by its key instead of by position.

product = {"name": "Notebook", "price": 120}
product["stock"] = 15
print(product.get("price", 0))

The program creates product information, adds stock later, and safely reads the price. Online shops, employee records, settings files, and API responses commonly use dictionaries because named fields are easy to understand.

.get() is useful when a key might be missing because it can return a default value instead of raising an error. A nested dictionary is a dictionary stored inside another value, useful for structured records.

Key words: key (lookup label), value (stored data), lookup (finding data), mutable (changeable), nested (inside another structure), and default (fallback value).

Creating Dictionaries

person = {
    "name": "Javanson",
    "age": 25,
    "city": "Nairobi",
    "is_dev": True
}

print(person)
print(person["name"])
{'name': 'Javanson', 'age': 25, 'city': 'Nairobi', 'is_dev': True} Javanson

Accessing & Modifying

person = {"name": "Javanson", "age": 25}

# Access
print(person["name"])
print(person.get("age"))
print(person.get("country", "Unknown"))   # Safe access

# Modify
person["age"] = 26
person["city"] = "Mombasa"
print(person)
Javanson 25 Unknown {'name': 'Javanson', 'age': 26, 'city': 'Mombasa'}

Dictionary Methods

person = {"name": "Javanson", "age": 25}

print(person.keys())
print(person.values())
print(person.items())

person.pop("age")
print(person)

person.update({"age": 26, "city": "Nairobi"})
print(person)
dict_keys(['name', 'age']) dict_values(['Javanson', 25]) dict_items([('name', 'Javanson'), ('age', 25)]) {'name': 'Javanson'} {'name': 'Javanson', 'age': 26, 'city': 'Nairobi'}

Looping Through Dicts

person = {"name": "Javanson", "age": 25, "city": "Nairobi"}

for key in person:
    print(key)

for key, value in person.items():
    print(f"{key}: {value}")
name age city name: Javanson age: 25 city: Nairobi

Nested Dictionaries

employees = {
    "dev1": {"name": "Javanson", "role": "Backend"},
    "dev2": {"name": "Alice", "role": "Frontend"}
}

print(employees["dev1"]["name"])
print(employees["dev2"]["role"])
Javanson Frontend

Common Errors & Bugs

KeyError: 'country'

Cause: Accessing a key that doesn't exist. Use .get() for safe access.

TypeError: unhashable type: 'list'

Cause: Using a list as a dictionary key. Only immutable types can be keys.
