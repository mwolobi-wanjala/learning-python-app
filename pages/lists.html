Store Many Values In Lists

A list stores several values in one ordered collection. Ordered means each item has a position, and mutable means the list can be changed after it is created. Positions are indexes starting at zero.

tasks = ["email client", "write report"]
tasks.append("send invoice")
for position, task in enumerate(tasks, start=1):
    print(position, task)

append() adds a task, and enumerate() provides a human-friendly number while looping. To-do apps, shopping carts, playlists, and search results commonly use lists because their contents can grow or change.

A slice such as tasks[:2] selects part of a list. A list comprehension is a short way to create a new list from existing items; use it only when its meaning stays clear to the reader.

Key words: element (one item), index (position), method (an operation attached to a value), mutable (changeable), slice (a selected range), and comprehension (compact collection-building syntax).

Accessing & Modifying

fruits = ["apple", "banana", "cherry"]

print(fruits[0])     # First
print(fruits[-1])    # Last

fruits[1] = "mango"  # Change value
print(fruits)
apple cherry ['apple', 'mango', 'cherry']

List Methods

fruits = ["apple", "banana"]

fruits.append("cherry")        # Add to end
fruits.insert(0, "mango")      # Insert at index
fruits.remove("banana")        # Remove value
fruits.pop()                   # Remove last
fruits.sort()                  # Sort alphabetically
fruits.reverse()               # Reverse order

print(fruits)
['mango', 'cherry', 'apple']

Slicing Lists

nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])    # From index 1 to 3
print(nums[:3])     # First three
print(nums[3:])     # From index 3
print(nums[::2])    # Every other
print(nums[::-1])   # Reversed
[20, 30, 40] [10, 20, 30] [40, 50, 60] [10, 30, 50] [60, 50, 40, 30, 20, 10]

List Comprehension

A concise way to build lists.

squares = [x**2 for x in range(1, 6)]
print(squares)

evens = [x for x in range(10) if x % 2 == 0]
print(evens)
[1, 4, 9, 16, 25] [0, 2, 4, 6, 8]

Lists as Python Arrays

Python lists provide the array-like behavior most programs need: ordered positions, a length, and fast access by index. Unlike a low-level fixed-type array, a list can hold mixed values and grow dynamically. Use a list for general application data; use array or NumPy when memory layout and numeric performance matter.

scores = [72, 81, 90]
    scores.append(88)
    average = sum(scores) / len(scores)

    print(scores)
    print(round(average, 1))
[72, 81, 90, 88] 82.8

sum() and len() are built-in functions that work with many iterables. Keeping this calculation separate from input and output makes it easier to reuse and test.

Common Errors & Bugs

IndexError: list index out of range

Cause: Accessing an index that doesn't exist. Check len(list).

ValueError: list.remove(x): x not in list

Cause: Removing an item that isn't in the list. Use if x in list first.
