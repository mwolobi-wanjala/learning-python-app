6. Strings

Master text manipulation with one of Python's most powerful features.

Home / Lesson 06

Understand Text Data

A string is text surrounded by quotes. It is made of characters, and each character has a position called an index. Python starts counting indexes at zero, so the first character is at position 0.

raw_name = "  amina mwolobi  "
name = raw_name.strip().title()
message = f"Welcome, {name}!"
print(message)

strip() removes extra whitespace, title() capitalizes words, and the f-string inserts the value into a sentence. This is useful when cleaning names from a form before saving them to a customer database or displaying them on a receipt.

Strings are immutable: a string method creates a new string instead of changing the original text. Slicing, such as text[:5], extracts a section for previews, codes, and file names.

Key words: character (one text symbol), whitespace (spaces or line breaks), index (a position), slice (a selected range), f-string (formatted text), and immutable (not changed in place).

Creating Strings

Strings are text wrapped in quotes. You can use single, double, or triple quotes.

first = 'Hello'
second = "World"
multi = """This is a
multi-line string"""

print(first, second)
print(multi)
Hello World This is a multi-line string

Common String Methods

text = "  Jans Tech Python  "

print(text.strip())          # Remove whitespace
print(text.upper())          # UPPERCASE
print(text.lower())          # lowercase
print(text.replace("Python", "Coding"))
print(text.split())          # Split into list
print(len(text))             # Length
Jans Tech Python JANS TECH PYTHON jans tech python Jans Tech Coding ['Jans', 'Tech', 'Python'] 21

Slicing

Extract parts of a string using [start:end:step].

name = "Javanson"

print(name[0])      # First character
print(name[-1])     # Last character
print(name[0:4])    # Characters 0 to 3
print(name[4:])     # From index 4 to end
print(name[::-1])   # Reverse the string

f-Strings (Formatted Strings)

The cleanest way to embed variables in text.

name = "Javanson"
age = 25
city = "Nairobi"

print(f"My name is {name}, I am {age} years old, from {city}.")
print(f"Next year I will be {age + 1}.")
My name is Javanson, I am 25 years old, from Nairobi. Next year I will be 26.

Common Errors & Bugs

IndexError: string index out of range

Cause: Trying to access a character beyond the string length.

name = "Jans"
# print(name[10])  # Error!
print(name[len(name)-1])  # Correct way to get last char
