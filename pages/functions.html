9. Functions

Write reusable blocks of code that make your programs modular and clean.

Home / Lesson 09

Build Reusable Functions

A function is a named group of instructions for one job. A parameter is the input name in the function definition; an argument is the actual value supplied when the function is called. return sends a result back to the caller.

def calculate_total(price, quantity):
    return price * quantity

total = calculate_total(25, 3)
print(total)  # 75

The function receives two values, performs the calculation, and returns the answer. An online shop can call the same function for every cart item instead of rewriting the multiplication each time.

A default parameter supplies a value when none is given. *args collects many positional values, and **kwargs collects named values. Scope describes where a variable can be used; keeping data local to a function reduces accidental changes elsewhere.

Key words: definition (creating a function), call (running it), parameter (input placeholder), argument (input value), return value (the result), and scope (where a name is visible).

Defining a Function

Use def to create a function. Call it by its name.

def greet():
    print("Hello from JANS TECH!")

greet()
greet()
Hello from JANS TECH! Hello from JANS TECH!

Parameters & Arguments

def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Javanson")
greet("Alice", "Hi")
greet(greeting="Hey", name="Bob")
Hello, Javanson! Hi, Alice! Hey, Bob!

Return Values

def add(a, b):
    return a + b

result = add(5, 7)
print(f"Sum is {result}")

def square(n):
    return n * n

print(square(4))
Sum is 12 16

*args and **kwargs

Accept a variable number of arguments.

def total(*numbers):
    return sum(numbers)

print(total(1, 2, 3, 4, 5))

def profile(**info):
    for key, value in info.items():
        print(f"{key}: {value}")

profile(name="Javanson", age=25, city="Nairobi")
15 name: Javanson age: 25 city: Nairobi

Variable Scope

counter = 0   # global

def increment():
    global counter
    counter += 1

increment()
increment()
print(counter)
2

Common Errors & Bugs

TypeError: greet() missing 1 required positional argument: 'name'

Cause: Calling a function without providing required arguments.

UnboundLocalError: local variable 'counter' referenced before assignment

Cause: Trying to modify a global variable inside a function without global.
